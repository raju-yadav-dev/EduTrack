# EduTrack

Modern Student Management System built with Kotlin and Jetpack Compose.

---

## Overview

EduTrack is a modern Android application designed to manage students, schools, batches, and educational records through a clean and professional Material 3 interface.

The app focuses on:

* Student management
* Batch organization
* School tracking
* Dynamic dashboards
* Real-time search
* Modern UI/UX
* Cloud backup architecture

EduTrack is built with scalable architecture to support future features like Firebase cloud sync, Room database, analytics, and multi-device backup.

 │    ├── StudentsScreen.kt

 │    └── SettingsScreen.kt
 │
 ├── Student.kt
